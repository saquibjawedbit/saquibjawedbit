# Hi, I'm Saquib 👋

**Full-stack engineer building browser, security and AI-agent tools in TypeScript and Python.**

I ship production code end to end: browser extensions, backend APIs, dashboards and the detection logic in between.

🟢 **Open to part-time and contract work.** Reach me on [LinkedIn](https://linkedin.com/in/mdsaquibjawed).

### What I work on

- **Browser extensions & security** — data-loss prevention, sensitive-data detection (PII, Aadhaar, phone numbers), redaction, site-visit policies
- **Backends & dashboards** — Node/TypeScript and Python APIs, alerting and email pipelines, analytics dashboards, auth (Google / Microsoft sign-in)
- **AI agents & tooling** — agent workflows, evals, scraping and automation actors
- **Mobile** — Flutter / Dart apps

### Tech
